# Concrete and Compute

How much of the announced AI build-out can you actually see on the ground? A personal analysis of five flagship US AI data-centre campuses. It uses public permits and regulatory filings, Epoch AI's open construction data, Copernicus Sentinel-2 imagery and NASA Black Marble night lights.

Every figure is sourced in the page's appendix.
